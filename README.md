# scoreprot

Score HTML/Markdown prot fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/scoreprot/

## Install / run

```bash
git clone https://github.com/theworker02/scoreprot.git
cd scoreprot
node src/cli.js
node --test
```
